# Registre des NEWSLETTERS culturelles suivies (canal Gmail).
# Affiché à titre de suivi dans le tableau de bord ; la collecte réelle se fait par le
# label Gmail « Agenda » (voir scripts/gmail_collect.py), pas par ce fichier.
#
# Format (un par ligne) :  nom;domaine;territoire;statut;url_inscription
#   statut :
#     actif    = inscription confirmée (double opt-in OK) → on reçoit
#     attente  = inscrit, opt-in/captcha à finaliser OU réception à vérifier
#     candidat = À S'ABONNER (pas encore inscrit) — clique l'URL, confirme dans Gmail,
#                puis applique le label « Agenda » au 1er mail reçu
#     inactif  = pas de newsletter sur le site
#   url_inscription : page où s'abonner (affichée en lien « s'abonner ↗ »).
#
# Rappel workflow pour passer candidat → actif :
#   1) s'inscrire via l'URL   2) confirmer le double opt-in dans Gmail
#   3) étiqueter le mail « Agenda »   4) passer la ligne en « actif » ici.
#
