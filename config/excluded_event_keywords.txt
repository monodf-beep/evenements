# Événements à NE JAMAIS valoriser (rejet déterministe, gratuit, avant tout appel LLM).
#
# Une ligne = une expression (mot ou phrase), accents ignorés, insensible à la casse.
# Si une fiche la contient, elle est rejetée automatiquement — jamais notée par le LLM,
# jamais publiée. Ligne vide et lignes # ignorées.
#
# DEUX PORTÉES, déclarées par un marqueur de section :
#   [partout]  (défaut) — cherché dans le TITRE, la DESCRIPTION et l'URL SOURCE ;
#   [titre]              — cherché dans le TITRE SEUL.
# Pourquoi (incident du 2026-08-04) : « btob » cherché partout a attrapé le Salone Auto
# Torino, salon automobile GRAND PUBLIC du périmètre, parce que l'article mentionnait au
# passage son volet BtoB. Le mot n'était pas mauvais, le CHAMP l'était. Règle du pouce :
# une expression qui décrit le PUBLIC (« réservé aux professionnels ») ou un nom de
# domaine va dans [partout] ; un mot qui peut n'être qu'une mention au fil du texte va
# dans [titre] — un titre, lui, nomme l'événement.
#
# L'URL SOURCE compte comme du texte : les points d'un domaine sont des frontières de
# mots, donc la ligne « businessfrance » matche event.businessfrance.fr. Inutile
# d'écrire l'URL entière.
#
# Pour retirer un événement DÉJÀ publié qui correspond à une règle ajoutée après coup :
#   .venv/bin/python -m scripts.audit_excluded_events            # liste (dry-run)
#   .venv/bin/python -m scripts.audit_excluded_events --apply    # corbeille + rejette
# TOUJOURS lire le dry-run : c'est lui qui a démasqué le faux positif ci-dessus.

# ══════════════════════════════════════════════════════════════════════════════════
# RÈGLE DE COMPOSITION — ce filtre rejette SANS JUGE, donc seuls les marqueurs sans
# ambiguïté entrent ici. Ne JAMAIS mettre seuls : « conférence », « salon »,
# « rencontre », « atelier », « forum », « masterclass », « workshop », « networking »,
# « colloque », « convegno », « séminaire », « congrès » (le Palais des Congrès est un
# LIEU de concerts !), « recrutement » (les associations recrutent des bénévoles),
# « team building » (boniment de lieu : « idéal pour vos team buildings » sur la page
# d'un château). Ces mots-là, c'est le LLM qui les juge en contexte — « Conférences &
# Rencontres » est une de nos onze catégories (docs/CHARTE_EDITORIALE.md).
#
# CONTRE-EXEMPLE de domaine à ne JAMAIS ajouter : us.list-manage.com — c'est le domaine
# de suivi de Mailchimp, présent dans TOUTE newsletter, y compris culturelle. Ce n'est
# pas un marqueur pro, c'est un facteur du courrier.
# ══════════════════════════════════════════════════════════════════════════════════
