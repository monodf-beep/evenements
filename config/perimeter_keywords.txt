# ⚠️ Comté de Nice ≠ Alpes-Maritimes. Les communes de l'ARRONDISSEMENT DE GRASSE
# (Cannes, Antibes, Grasse, Cagnes-sur-Mer, Vence, Mougins, Valbonne/Sophia Antipolis,

# 2026-08-03 : elles sont hors périmètre, pas « sans étiquette ».
#
# Ce fichier n'est PAS l'endroit où se décide l'appartenance d'une commune : c'est un
# filtre POSITIF grossier, cherché dans du TEXTE LIBRE (titre + description), donc
# incapable de trancher un nom ambigu (« Vence » ⊂ « Provence », « Grasse » ⊂ « grasse
# matinée », « Cannes » ⊂ « cannes à pêche »). La décision exacte se prend sur le champ
# `ville`, via utils.sources.est_arrondissement_grasse() (liste officielle des 62
# communes, config/communes_comte_de_nice.json), appliquée dans scripts/evaluator.py
# (pré-filtre gratuit) et scripts/purge_out_of_zone.py (rattrapage rétroactif).

# « Alpes-Maritimes », « Cote d'Azur » et « Riviera » sont VOLONTAIREMENT conservés :
