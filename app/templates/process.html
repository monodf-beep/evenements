📡 Collecte

On ramasse les événements de trois familles de sources :

  • Flux RSS des institutions et lieux culturels
  • Newsletters Gmail (label « Agenda »)
  • Dossiers de presse (label « Presse »)

Chaque événement entre en base au statut pending. Le radar presse sert seulement à détecter — jamais crédité ni lié (charte).

⚙️ Préparation (automatique, idempotent)

  • Déduplication — fusionne le même événement vu sur plusieurs sources
  • Datation — extrait la vraie date (page structurée → texte FR/IT)
  • Évaluation IA — note l'intérêt éditorial de 0 à 10 🧠
  • Enrichissement — recherche + rédige l'article (pour les retenus) ✍️
  • Visuels — photo : og:image → Wikimedia Commons → bannière 🖼️

🛡️ Porte qualité

Un événement ne part en brouillon que s'il est COMPLET et à venir :

DateLieuVille TerritoireCatégorieImage
✅ complet → poussé en brouillon ⛔ incomplet → reste dans « À compléter »
▼les incomplets entrent dans la boucle
4

🔄 Agent d'auto-complétion boucle

Pour chaque événement incomplet, il essaie de combler les trous, du plus sûr au dernier recours :

  • Date — page structurée → texte (IA)
  • Lieu / Ville — page → texte (IA) → agent recherche web 🌐
  • Image — og:image → Commons → agent recherche web + agent vérificateur vision 👁️ (« cette photo correspond-elle au sujet ? oui / non »)

Puis il re-vérifie la complétude — c'est la boucle : incomplet → complété → re-contrôlé.

↺ re-passe par la porte qualité après chaque tentative

5

📰 WordPress — toujours en brouillon

Rien n'est mis en ligne automatiquement. Deux cibles distinctes :

  • culturasabauda.eu — articles (les phares, score ≥ 7)
  • agendasabauda.eu — événements The Events Calendar (la masse)

Tu fais la publication finale à la main, quand tu veux.

🧠 Les agents IA

  • Évaluateur — note l'intérêt éditorial (0–10).
  • Agent lieu — recherche web quand la source ne dit pas où ça se passe.
  • Agent image — cherche une photo du sujet…
  • Vérificateur vision — …et un second agent confirme qu'elle correspond au sujet avant de l'accepter.

🔄 Les boucles

  • Boucle période — un événement long (expo) réapparaît chaque week-end.
  • Boucle qualité — incomplet → complété → re-vérifié → poussé.
  • Anti-spam Slack — on ne re-signale un événement que si son état a changé.
