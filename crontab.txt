# Agenda Backoffice — Cultura Sabauda
# Installer avec : crontab crontab.txt   (puis vérifier : crontab -l)
#
# Chemins = déploiement VPS réel : projet sous /root/evenements, interpréteur du
# venv (.venv/bin/python). Adapter si le projet est ailleurs.
# Heures en heure locale du serveur (timezone Europe/Paris — voir timedatectl).

# Scraping RSS quotidien 8h
0 8 * * * cd /root/evenements && .venv/bin/python scripts/scraper_events.py >> logs/scraper.log 2>&1
# Collecte des newsletters (label Gmail « Agenda ») 8h15
15 8 * * * cd /root/evenements && .venv/bin/python scripts/gmail_collect.py >> logs/gmail.log 2>&1
# Déduplication multi-sources 8h30 (avant l'évaluation → évite d'évaluer des doublons)
30 8 * * * cd /root/evenements && .venv/bin/python scripts/dedupe.py >> logs/dedupe.log 2>&1
# Datation 8h45 : extrait la vraie date d'événement (déterministe, gratuit) → filtres par période
45 8 * * * cd /root/evenements && .venv/bin/python scripts/dates.py >> logs/dates.log 2>&1
# Évaluation LLM 9h (après scraping)
# NB : le cron évalue TOUTE la file pending (rattrapage quotidien). Le pilotage par
# période (« ce week-end ») se fait à la MAIN via le bouton du dashboard.
0 9 * * * cd /root/evenements && .venv/bin/python scripts/evaluator.py >> logs/evaluator.log 2>&1
# Rédaction LLM 9h30 (après évaluation) — --cap prudent pour un premier lancement en
# autonome (voir docs/BACKLOG.md 2026-07-31 : garde-fou eventness + kill-switch quota
# déjà en place dans enrich.py, ajuster le plafond une fois la fiabilité confirmée).
30 9 * * * cd /root/evenements && .venv/bin/python scripts/enrich.py --cap 20 >> logs/enrich.log 2>&1
# Publication Agenda Sabauda 11h (laisse une marge à la rédaction, qui peut prendre du
# temps sur les articles longs) — ne publie que le complet (utils.completeness), saute
# le reste sans erreur.
0 11 * * * cd /root/evenements && .venv/bin/python scripts/publish_batch_as.py --cap 20 >> logs/publish_as.log 2>&1
# Sauvegarde de la base 3h (copie cohérente horodatée, garde les 14 dernières) — anti perte de données
0 3 * * * cd /root/evenements && .venv/bin/python scripts/backup_db.py >> logs/backup.log 2>&1
